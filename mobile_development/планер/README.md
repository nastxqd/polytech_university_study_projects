# Study Planner

**Study Planner** — настольное WPF-приложение для планирования учебной нагрузки.

Программа помогает студенту хранить учебные задачи, контролировать дедлайны, распределять нагрузку по ближайшим дням и отслеживать прогресс выполнения.

## Возможности

- добавление учебной задачи через форму быстрого ввода;
- выбор предмета и дедлайна;
- отметка задачи как выполненной;
- автоматический пересчёт процента выполнения;
- расчёт количества задач на сегодня;
- расчёт примерного времени учебной нагрузки;
- график нагрузки на ближайшие семь дней;
- статистика активных задач по предметам;
- фильтрация задач по предмету;
- цветовое отображение приоритетов;
- демонстрационные данные при первом запуске;
- локальное сохранение данных без подключения к интернету.

## Интерфейс

Главный экран приложения состоит из нескольких частей:

- боковое меню навигации;
- карточка выполненных задач;
- карточка задач на текущий день;
- карточка планируемого времени;
- график нагрузки по дням;
- статистика по предметам;
- список ближайших задач;
- форма быстрого добавления новой задачи.


```powershell

```

## Хранение данных

Задачи сохраняются локально в файл:

```text
%LocalAppData%\StudyPlanner\tasks.json
```

Файл создаётся автоматически при первом добавлении или изменении задачи.

При первом запуске, если сохранённых данных ещё нет, приложение загружает демонстрационный список задач.

## Принцип работы

1. При запуске приложение загружает задачи из `tasks.json`.
2. Если файл отсутствует, создаются демонстрационные задачи.
3. Пользователь добавляет задачу через форму.
4. Задача помещается в список объектов `StudyTask`.
5. Список сохраняется в JSON-файл.
6. Интерфейс обновляет карточки, график и список задач.
7. При отметке выполнения статистика пересчитывается автоматически.
