# FractionTrainer — тренажёр дробей

Курсовой проект по дисциплине «Разработка мобильных приложений».

**Студентка:** Андриянова А. А.

**Группа:** 231-361

**Университет:** Московский политехнический университет, 2026 год.

FractionTrainer помогает изучать дроби через выбор частей фигуры, числовой ввод и карточные задания. В курсовой работе рассмотрена архитектура приложения, выполнены доработки пользовательских сценариев и проверена корректность основных операций.

Проект написан на C# и .NET 10. Основная логика вынесена в библиотеку классов `FractionTrainer.Core`, которую используют графическое приложение WPF и консольная версия.

## Возможности

В графическом приложении доступны шесть типов заданий:

1. **Сбор дроби:** выбрать нужное количество частей фигуры.
2. **Определение дроби:** ввести числитель и знаменатель по рисунку.
3. **Сравнение:** выбрать большую из двух дробей.
4. **Дополнение до целого:** ввести количество недостающих частей.
5. **Поиск равной дроби:** выбрать эквивалентную дробь из четырёх вариантов.
6. **Поиск пар:** сопоставить шесть карточек, образующих три пары.

Тип задания выбирается случайно при нажатии «Новая задача».

Предусмотрены два режима:

- **Обучение:** доступен показ правильного ответа.
- **Проверка знаний:** доступна проверка ответа и счётчик попыток. При ошибке приложение может показать правильное значение.

Также доступны светлая и тёмная темы, восемь акцентных цветов, сохранение пользовательских настроек, справка и горячие клавиши.

| Сложность | Допустимые знаменатели |
|---|---|
| Лёгкая | 2, 3, 4 |
| Средняя | 2, 3, 4, 5, 6 |
| Сложная | 2, 3, 4, 5, 6, 8, 10 |

Консольная версия выполняет задания на сбор дроби, сохраняет результаты сессий, показывает историю и экспортирует её в CSV.

## Требования

- Windows для графического приложения WPF и отдельной проверки интерфейса.
- .NET SDK 10. Проверки выполнены с SDK 10.0.401.
- Visual Studio Code либо Visual Studio для работы с исходным кодом. Запуск возможен также через обычный cmd.
- Доступ к NuGet для первоначального восстановления зависимостей тестового проекта.

В `global.json` задан SDK 10.0.100 с разрешённым переходом на более новый feature band в рамках .NET 10. Текущая графическая версия является настольным приложением для Windows.

## Запуск в Visual Studio Code

1. Открыть папку `Курсовой проект/FractionTrainer` через «Файл → Открыть папку».
2. Выбрать «Терминал → Создать терминал».
3. Выполнить команды по очереди:

```powershell
dotnet restore FractionTrainer.sln --configfile NuGet.Config
dotnet build FractionTrainer.sln --no-restore
dotnet run --project FractionTrainer.WPF/FractionTrainer.WPF.csproj --no-restore
```

После запуска откроется графическое приложение.

## Запуск из cmd

Открыть папку `FractionTrainer` в проводнике Windows, в адресной строке ввести `cmd` и нажать Enter. Командная строка откроется в папке решения.

Если cmd уже открыт в корне репозитория, сначала перейти в папку решения:

```cmd
cd /d "Курсовой проект\FractionTrainer"
```

Запуск графической версии:

```cmd
dotnet run --project FractionTrainer.WPF/FractionTrainer.WPF.csproj
```

Запуск одной консольной задачи:

```cmd
dotnet run --project FractionTrainer.Console/FractionTrainer.Console.csproj -- --mode quiz --count 1 --difficulty easy
```

VS Code не требуется для запуска этих команд. Необходимо, чтобы .NET SDK был установлен и команда `dotnet` была доступна.

## Работа с графическим приложением

1. Открыть раздел «Тренажёр».
2. Выбрать режим и сложность справа.
3. Нажать «Новая задача». Изменение сложности применяется при генерации следующей задачи.
4. Выполнить действие, указанное в условии.
5. В режиме проверки знаний нажать «Проверить». Для поиска пар проверка выполняется при выборе второй карточки.
6. Для очистки ответа нажать «Сбросить». Условие задачи останется прежним.

В обучении кнопка «Показать ответ» отображает решение. При определении дроби принимается эквивалентная запись: например, `2/4` вместо `1/2`. При дополнении до целого вводится число недостающих долей: для `3/4` ответом является `1`.

В разделе «Настройки» можно выбрать тему, акцентный цвет, сложность и режим по умолчанию. Тема и акцент применяются сразу. Для сохранения выбора между запусками необходимо нажать «Сохранить».

После сохранения цвет основной фигуры обновляется при возвращении в тренажёр. Для обновления цвета уже созданных карточек следует создать новую задачу. Режим и сложность по умолчанию загружаются при создании экрана тренажёра, например после перезапуска приложения.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| F1 | Открыть справку |
| Ctrl+N | Создать новую задачу в тренажёре |
| Ctrl+R | Сбросить ответ в тренажёре |
| Escape | Сбросить ответ в тренажёре |
| Ctrl+T | Переключить тему |

## Работа с консольной версией

Все команды ниже выполняются из папки `FractionTrainer`.

### Справка

```cmd
dotnet run --project FractionTrainer.Console/FractionTrainer.Console.csproj -- --help
```

Отдельные `--` отделяют параметры `dotnet run` от аргументов самого приложения.

### Проверка знаний

```cmd
dotnet run --project FractionTrainer.Console/FractionTrainer.Console.csproj -- --mode quiz --count 3 --difficulty easy
```

Программа предлагает собрать дробь и просит ввести номера выбранных частей через запятую. **Нумерация начинается с нуля. Вводить саму дробь вместо индексов не нужно.**

Пример:

```text
Задача 1/3: Собери дробь 2/3
Всего секторов: 3
Введи номера выбранных секторов через запятую (0-based): 0,1
```

После ввода нажать Enter. Для `2/3` подходят любые два разных индекса из `0`, `1`, `2`.

| Целевая дробь | Пример ввода |
|---|---|
| 1/2 | `0` |
| 2/3 | `0,1` |
| 3/4 | `0,1,2` |

Повторный ввод одного индекса переключает состояние части, поэтому индексы не следует повторять. По окончании задач выводится результат и сохраняется сессия.

### Обучение с подсказкой

```cmd
dotnet run --project FractionTrainer.Console/FractionTrainer.Console.csproj -- --mode learning --count 2 --difficulty easy --show-answer
```

Перед вводом программа покажет правильные индексы. Ответ всё равно необходимо ввести самостоятельно.

### История и экспорт

Последние десять сессий:

```cmd
dotnet run --project FractionTrainer.Console/FractionTrainer.Console.csproj -- --history
```

Экспорт истории в текущую папку:

```cmd
dotnet run --project FractionTrainer.Console/FractionTrainer.Console.csproj -- --export-csv history.csv
```

### Параметры

| Параметр | Назначение |
|---|---|
| `--mode learning` или `--mode quiz` | Режим работы |
| `--difficulty easy`, `medium` или `hard` | Сложность |
| `--count N` | Количество задач; использовать положительное целое число |
| `--show-answer` | Показ правильных индексов в режиме обучения |
| `--history` | Просмотр последних десяти сессий |
| `--export-csv <путь>` | Экспорт истории в CSV |
| `--help` или `-h` | Справка |

Без параметров запускаются обучение, лёгкая сложность и пять задач. Прервать консольную тренировку можно сочетанием Ctrl+C; незавершённая сессия при таком прерывании не сохраняется.

## Основные классы

| Класс | Назначение |
|---|---|
| `Fraction` | Числитель, знаменатель, проверка эквивалентности и сокращение |
| `FractionPuzzle` | Целевая дробь, множество выбранных частей, проверка решения и события |
| `PuzzleGenerator` | Генерация условий с учётом сложности |
| `ComparePuzzle`, `CompleteToWholePuzzle`, `EquivalentPuzzle`, `FindPairsPuzzle` | Модели отдельных типов заданий |
| `AppSettings`, `SettingsService` | Данные настроек и их сохранение в JSON |
| `PuzzleAttempt`, `PuzzleSession`, `SessionResult` | Попытки и итоговая статистика сессии |
| `JsonScoreRepository` | Хранение истории консольных сессий |
| `App`, `MainWindow` | Запуск WPF, оформление, навигация и горячие клавиши |
| `TrainerViewModel`, `SettingsViewModel` | Состояние экранов и обработка действий |
| `ObservableObject` | Уведомления `PropertyChanged` |
| `RelayCommand` | Связь команд интерфейса с методами |
| `FractionCircleControl` | Отрисовка фигур и обработка нажатий на части |
| `Program` в Console | Разбор параметров, ввод ответов и запуск сессии |

В объектной модели используются свойства, события, коллекции `HashSet<int>` и `List<T>`, наследование ViewModel от `ObservableObject`, а также интерфейсы `IPuzzleGenerator`, `ISettingsService` и `IScoreRepository`.

## Хранение данных

Данные создаются в пользовательском каталоге:

```text
%AppData%\FractionTrainer\
├── settings.json    # Пользовательские настройки
└── scores.json      # История консольных сессий
```

История и экспорт CSV доступны в консольной версии. Счётчик графического тренажёра хранится в памяти и пока не записывается в общую историю.

## Тестирование

После восстановления зависимостей, из папки `FractionTrainer`:

```cmd
dotnet test FractionTrainer.sln --no-restore
```

Модульные тесты проверяют дроби, состояние задания и генерацию. Регрессионные проверки создают по 200 карточных полей для каждого уровня сложности и проверяют наличие трёх пар; также проверяется единственность правильного варианта эквивалентной дроби.

Отдельная проверка WPF и файлового хранения, из той же папки:

```cmd
dotnet run --project ../Проверки/Smoke.csproj -- ../.verification-output
```

Программа создаёт служебное окно вне видимой области, проверяет реальные привязки, оформление, сброс, ответы, завершение пар и JSON-хранение. Тестовые файлы и рендеры сохраняются в `.verification-output` в папке курсового проекта. Пользовательские настройки при этом не изменяются.

## Ограничения и дальнейшее развитие

- Геометрия некоторых сложных фигур требует уточнения. Круг и прямоугольник являются основными представлениями равных долей.
- Результаты WPF пока не сохраняются в историю сессий.
- Флаг `ShowHints` сохраняется, но ещё не управляет подсказками тренажёра.
- Повторная проверка одного задания учитывается как новая попытка.
- Требуется расширить обработку повреждённых JSON-файлов, ошибок доступа и слишком больших чисел.
- В справке сохранился старый текст о кнопках изменения числа долей, отсутствующих в текущем интерфейсе.
