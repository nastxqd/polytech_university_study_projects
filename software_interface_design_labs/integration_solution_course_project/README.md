# Комплект курсового проекта

Тема: «Разработка интеграционного решения для взаимодействия информационных систем предприятия». В качестве учебного примера используется интернет-магазин «ТехноДом»: веб-витрина, склад, платёжный шлюз и CRM.

## Файлы

- `Курсовой_проект_Интеграция_записка.docx` — пояснительная записка с архитектурой, контрактами, диаграммами, обработкой ошибок, результатами тестирования и списком источников.
- `Презентация_курсовой_интеграция.pptx` — презентация для защиты на 9 слайдов.
- `prototype/` — исходный код прототипа, JSON Schema, AsyncAPI и тесты.


## Запуск

Требуется Python 3.10 или новее; внешние библиотеки не нужны.

```powershell
cd prototype
python app.py
```

Проверки запускаются отдельно:

```powershell
python -m unittest -v
```

Последний запуск прошёл: 7 тестов завершились `OK` (4 проверки доменной логики и 3 HTTP/JSON проверки).

## Границы учебной модели

Платёжный шлюз, брокер и CRM имитируются локально. Нагрузочные, отказоустойчивые и безопасностные испытания не проводились; экономическая окупаемость не рассчитывалась без исходных данных предприятия. Промышленное внедрение требует подключения реальных систем, согласования контрактов, TLS и доступа, настройки брокера и повторной проверки на целевой инфраструктуре.
