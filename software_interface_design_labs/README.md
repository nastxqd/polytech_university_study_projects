Проектирование интеграционных решений
Репозиторий содержит лабораторные работы по дисциплине «Проектирование интеграционных решений». На примере сети медицинских центров «МедЛайн» рассматриваются анализ информационных систем, формирование требований и проектирование обмена данными.
Цель проекта
Спроектировать интеграционное решение, которое обеспечивает своевременную передачу данных между системами, согласованность справочников и возможность отслеживать обработку сообщений.
Основной сценарий — передача сведений об оказанных медицинских услугах из медицинской системы MedCore в систему финансового учёта FinanceMed.

Предметная область
В рассматриваемый ИТ-ландшафт входят:
- MedCore — медицинская информационная система.
- LabSystem — лабораторная система.
- ImageArchive — архив медицинских изображений.
- MedCRM — система взаимодействия с пациентами.
- PatientPortal — личный кабинет пациента.
- FinanceMed — система финансового учёта.
- MedBI — аналитическая система.
Ключевые объекты интеграции: пациент, медицинская услуга и факт оказания услуги. Владение данными определяется по сущностям и атрибутам: MedCore отвечает за медицинские сведения, MedCRM — за контактные данные, FinanceMed — за финансовые операции и платежи.
Предлагаемое решение
Для взаимодействия MedCore и FinanceMed предлагается заменить суточную CSV-выгрузку асинхронной передачей событий через брокер сообщений.
1. MedCore регистрирует оказанную услугу и формирует событие ServiceProvided.
2. Брокер принимает сообщение и передаёт его FinanceMed.
3. FinanceMed проверяет данные и наличие ранее обработанного события.
4. При получении нового события система обновляет необходимые справочники и сохраняет финансовую операцию.
5. Результат обработки фиксируется для контроля и диагностики.
Основные требования к решению:
- Доступность в FinanceMed не менее 95% зарегистрированных услуг в течение 15 минут.
- Сохранность данных при временной недоступности получателя.
- Повторная доставка без создания дублирующих записей.
- Использование сквозных идентификаторов пациента и услуги.
- Защищённый обмен и аутентификация систем.
- Отслеживание состояния сообщений и поддержка версий контракта.
