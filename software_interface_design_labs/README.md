# Проектирование интеграционных решений

Репозиторий содержит лабораторные работы по дисциплине «Проектирование интеграционных решений».

На примере сети медицинских центров «МедЛайн» рассматриваются анализ информационных систем, формирование требований и проектирование обмена данными.

## Цель

Разработать проект интеграционного решения для передачи сведений об оказанных медицинских услугах из MedCore в FinanceMed.

## Лабораторные работы

| Работа | Тема |
| --- | --- |
| Лабораторная работа № 1 | Основы интеграции информационных систем. Аудит ИТ-ландшафта и анализ существующих взаимодействий. |
| Лабораторная работа № 2 | Формирование требований к интеграционному решению и выбор архитектурного подхода. |
| Лабораторная работа № 3 | Проектирование модели данных, правил преобразования и интеграционного контракта. |

## Основные системы

- **MedCore** — медицинская информационная система.
- **LabSystem** — лабораторная система.
- **ImageArchive** — архив медицинских изображений.
- **MedCRM** — система взаимодействия с пациентами.
- **PatientPortal** — личный кабинет пациента.
- **FinanceMed** — система финансового учёта.
- **MedBI** — аналитическая система.

## Основной сценарий интеграции

Передача данных об оказанных услугах из MedCore в FinanceMed для финансового учёта.

Предлагаемое решение предусматривает асинхронный обмен через брокер сообщений с использованием события `ServiceProvided`.

Основные требования:

- своевременная передача данных;
- сохранность сообщений при временной недоступности систем;
- обработка повторных сообщений без создания дублей;
- использование единых идентификаторов пациента и услуги;
- защищённый обмен данными;
- отслеживание состояния обработки сообщений;
- поддержка версий интеграционного контракта.

## Содержание материалов

В лабораторных работах представлены:

- анализ существующей архитектуры;
- функциональные и нефункциональные требования;
- сравнение способов интеграции;
- диаграммы взаимодействия систем;
- модель владения данными;
- правила сопоставления и преобразования полей;
- пример интеграционного сообщения в формате JSON.
